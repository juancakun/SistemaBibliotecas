Library Management System

A console-based Library Management System developed in Java to practice Object-Oriented Programming (OOP), collections, object relationships, and business logic implementation.

Overview

This project simulates the basic operations of a library. Users can register books and library members, manage book loans and returns, and keep track of active and historical loans.

The main goal of this project is to strengthen Java programming fundamentals and object-oriented design concepts.

Features
Add new books
Register users
Display available books
Search books by ID or title
Search users by ID or name
Create book loans
Return borrowed books
View active loans
View loan history
Automatic ID generation for entities

Technologies

Descripción

Este proyecto simula el funcionamiento básico de una biblioteca mediante una aplicación de consola desarrollada en Java.

Permite administrar libros, usuarios y préstamos, aplicando conceptos fundamentales de Programación Orientada a Objetos y estructuras de datos.

Funcionalidades
Agregar libros al catálogo
Registrar usuarios
Mostrar libros disponibles
Buscar libros por ID o título
Buscar usuarios por ID o nombre
Realizar préstamos
Devolver libros
Consultar préstamos activos
Consultar historial de préstamos
Generación automática de identificadores
